Vice Cover Studio turns a photo and a caption into GTA 6-poster-style cover art — a multi-panel cover look with bold lettering and a Vice City sunset or neon colour grade — and exports it as a PNG to share. It runs fully offline in a desktop browser from its own static files; photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
